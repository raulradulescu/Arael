# Decompile Function

Decompile the function: $ARGUMENTS

Use the `arael_decompile` MCP tool to get C pseudocode for the specified function.

The argument can be:
- Function name (e.g., `main`, `validate_password`)
- Function address (e.g., `0x401000`)

After decompiling, explain what the function does and highlight:
- Input validation
- Crypto operations
- String comparisons
- Suspicious patterns
