# Cross-References

Find cross-references for: $ARGUMENTS

Use the `arael_xrefs` MCP tool to find all references to/from the specified address or function.

The argument can be:
- Function name (e.g., `decrypt`)
- Address (e.g., `0x401000`)

Show:
- Who calls this function (callers)
- What this function calls (callees)
- Data references
