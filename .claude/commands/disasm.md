# Disassemble Function

Disassemble the function: $ARGUMENTS

Use the `arael_disassemble` MCP tool to get assembly for the specified function.

The argument can be:
- Function name (e.g., `main`)
- Function address (e.g., `0x401000`)

After disassembling, explain:
- Calling convention used
- Key instructions (comparisons, jumps, calls)
- Anti-debugging tricks if present
